## What was done

- **Standalone.** New code, no root modules, no root data. Own IndexedDB
  database (`qurOS`) and `qos_*` keys, so it can sit beside root on
  hpcurate.github.io without touching it. Same look: #0e0e0e, #A78BFA, Syne +
  JetBrains Mono (bundled), hairlines, flat shapes. New icon (a Bauhaus "q").
- **DUMP** (home): talk or write; a topic per dump (free, evening, a custom
  tag, a map section or item); next untouched map item; everything captured by
  day; an entry screen to edit, re-topic, keep talking, copy, share or delete.
- **The lock.** A voice dump keeps the screen on (Screen Wake Lock, re-taken
  whenever the page comes back) and starts locked: every touch swallowed except
  slide-to-unlock, the back gesture refused, dims to near-black after 20 s,
  drifts a few pixels against burn-in, re-locks after 15 s idle, toasts can't
  be tapped. The orb shows the state — circle listening, square paused, grey
  triangle for a problem (never red). Live words on the lock screen (can be
  turned off), timer, word count, EN/FR quick switch.
- **Speech-to-text that survives a phone:** auto-restart after silences and
  network drops; Android's repeated-phrase results de-duplicated; unfinished
  tails kept; "new paragraph" / "new line" commands; paragraphs after a pause.
- **Never lose words:** every phrase is on disk at once; an unsaved dump is
  offered back on the next start, and is saved before a new one can replace it.
- **DAY:** the flex system rebuilt for input — wake/bed, one NEXT action, goals
  (3/day, 3/week, carry/drop), the morning chain (full/minimum/not today, auto
  filled from wake time, gym, hygiene, CAP pomodoro, the walk dump), bad-day
  mode, hygiene, focus by area, check-in 1–5, meals, evening prep and dump.
- **GYM:** A/B rotation, sets prefilled from last time (one tap repeats), "add
  weight", minimum session, rest timer with vibration, screen kept on.
- **MAP:** the life-dump map from a `.md` file / paste / starter; tiers;
  untouched/started/covered; dumps per item; editing that keeps states and
  dump links; export back to `.md`.
- **SEND:** everything new since the last export as one markdown file (schema
  2) with an editable instruction block for the chat, or JSON; share sheet
  (straight into the Claude app), copy, or file; marks sent with undo; send
  history with re-share; full backup / restore (merge or replace).
- **Settings:** every list and timing editable — voice, lock, dim, re-lock,
  paragraphs, rollover hour, chain with minimums, hygiene, areas, prep, meal
  slots, scales, the gym program, the export instruction, accent colour, data.
- **Offline shell** (service worker), installable PWA with Talk / Write / Day
  shortcuts.

Not carried over from v1.0.0: the recipe library and Todoist grocery trips
(STORE's job), the shower timer, root's other apps.
